# Интервью с заказчиком: личный кабинет пользователя

## 1. Цель интервью

Выяснить потребности заказчика, определить цели создания личного кабинета пользователя, собрать основные требования и согласовать границы первой версии продукта.

## 2. Вопросы для заказчика

### Блок 1. Бизнес-цели

1. Почему компания решила создать личный кабинет пользователя?
2. Какую основную проблему должен решить личный кабинет?
3. Как компания сейчас решает эту проблему?
4. Как мы поймём, что запуск личного кабинета прошёл успешно?
5. Какие показатели необходимо улучшить после запуска продукта?

### Блок 2. Пользователи

6. Кто будет пользоваться личным кабинетом?
7. Какие задачи пользователи должны решать с его помощью?
8. С какими трудностями пользователи сталкиваются сейчас?
9. Будут ли разные категории пользователей с разными правами доступа?

### Блок 3. Функциональность

10. Какие основные функции должны быть доступны в первой версии личного кабинета?
11. Должен ли пользователь иметь возможность регистрироваться самостоятельно?
12. Как пользователь должен входить в личный кабинет?
13. Какие личные данные пользователь должен видеть и изменять?
14. Должен ли пользователь видеть историю своих заказов?
15. Какие сведения о каждом заказе необходимо отображать?
16. Нужно ли показывать текущий статус заказа?
17. Нужна ли возможность отменять заказы?
18. Нужны ли уведомления об изменении статуса заказа?

### Блок 4. Ограничения и интеграции

19. С какими существующими системами необходимо взаимодействовать личному кабинету?
20. Есть ли ограничения по срокам и бюджету?
21. Есть ли требования к безопасности и защите персональных данных?
22. Должен ли личный кабинет работать на компьютерах и мобильных устройствах?

### Блок 5. Границы проекта

23. Какие функции обязательно должны войти в первую версию?
24. Какие функции можно отложить на будущее?
25. Должна ли быть доступна онлайн-оплата в личном кабинете?
26. Нужно ли включать программу лояльности или бонусную систему в первую версию?
27. Какие возможности точно не входят в текущий проект?

## 3. Уточняющие вопросы

Если заказчик даёт общий ответ, необходимо уточнить детали.

Пример:

Ответ заказчика: «Личный кабинет должен быть удобным».

Уточняющие вопросы:
- Что именно пользователь должен уметь делать?
- Какие действия сейчас занимают больше всего времени?
- Как можно измерить улучшение удобства?
- Есть ли конкретные примеры проблем пользователей?

## 4. Результат интервью

По итогам встречи необходимо определить:
- Основные бизнес-цели.
- Целевых пользователей.
- Основные функции личного кабинета.
- Бизнес-ограничения и требования к качеству.
- Критерии успеха проекта.
- Функции, входящие в проект (In Scope).
- Функции, не входящие в проект (Out of Scope).
- Открытые вопросы, требующие дополнительного обсуждения.
